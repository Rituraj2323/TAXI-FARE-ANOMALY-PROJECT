🚖 Taxi Fare Anomaly Detection System

📌 Overview

This project is a Taxi Fare Anomaly Detection System that identifies unusual or suspicious taxi fares using machine learning and backend APIs.

It consists of:
	•	A backend for processing and prediction
	•	A dashboard (frontend) for visualization
	•	An additional Django backend (optional/experimental)
	•	A notebook for model development

  🚀 How to Run


1️⃣ Clone the repository

git clone https://github.com/Rituraj2323/TAXI-FARE-ANOMALY-PROJECT.git
cd TAXI-FARE-ANOMALY-PROJECT

2️⃣ Run Backend

cd taxi-anomaly-backend
npm install
npm start


3️⃣ Run Frontend

cd taxi-anomaly-dashboard
npm install
npm run dev


4️⃣ Run Django Backend (Optional)

cd taxi-django-backend
pip install -r requirements.txt
python manage.py runserver

5️⃣ Run Notebook

notebook.ipynb

🌐 Deployment

	•	Frontend can be deployed on Vercel
